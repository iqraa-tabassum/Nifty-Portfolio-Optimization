QuantFolio: Data-Driven Portfolio Construction & Risk Analytics
Walk-forward backtested portfolio optimizer on 10 Nifty stocks (Python)
This Python tool picks the best mix of 10 big Indian stocks using math, and checks how risky that mix is. Every 3 months it chooses a new mix using only old data, then we see how it does in the next 3 months, with trading costs included. The tool's mix earned **11.75% per year**, while investing equally in all stocks earned 6.46% and the Nifty 50 earned 4.71%. This is one time period only, so future results can be different.
 Python · pandas · NumPy · SciPy · scikit-learn · matplotlib
